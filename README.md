# CP2 — Coding for Security

Projeto desenvolvido para a disciplina de **Coding for Security**, reunindo os exercícios do Check Point 2.

## Conteúdos

- MySQL e MongoDB
- Migração de dados relacionais para documentos
- Índices TTL e agregações
- Transações e auditoria
- SQL Injection e proteção por whitelist
- Autenticação e controle de acesso
- XSS e Content Security Policy
- Machine Learning aplicado à segurança
- Rate limiting e detecção de anomalias
- Análise e correção de vulnerabilidades
